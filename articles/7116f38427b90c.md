# full-stack-fastapi-templateの紹介

リポジトリをクローン後は、Docker（`docker compose up -d`）で起動することができました。

公式が出しているだけあって基本的な機能は揃っているようです。


## バックエンドの技術スタックまとめ

### 1. コアフレームワーク & 言語

Language: Python 3.10+
Framework: FastAPI (fastapi[standard])
Package Manager: uv (tool.uv) - 非常に高速なパッケージ管理ツールを採用
### 2. データベース & ORM

Database: PostgreSQL 17 (Dockerリング)
ORM: SQLModel (Pydantic + SQLAlchemy)
Migration: Alembic

### 3. 認証 & セキュリティ

Auth: OAuth2 / JWT (pyjwt)
Hashing: Bcrypt (passlib, bcrypt)
Validation: Pydantic

### 4. インフラ & ツール

Container: Docker Compose
Proxy: Traefik (リバースプロキシ/SSL)
Linting/Formatting: Ruff (Rust製の高速リンター)
Type Checking: MyPy (strict)
Testing: Pytest


## フロントエンドの技術スタックまとめ

### 1. コアフレームワーク & ビルド
Framework: React 19 (react, react-dom)
Build Tool: Vite 7 (vite) + SWC (@vitejs/plugin-react-swc)
Language: TypeScript (typescript)
Type Checking: Strict Mode (presumed)

### 2. ルーティング & 状態管理 (The "TanStack" Ecosystem)
Routing: TanStack Router (@tanstack/react-router)
ファイルベースルーティングと型安全なナビゲーションを採用 (
routeTree.gen.ts
 が生成されています)
Data Fetching/State: TanStack Query (@tanstack/react-query)
サーバー状態の管理とキャッシングに使用

### 3. UI & スタイリング
CSS Framework: Tailwind CSS 4 (tailwindcss v4, @tailwindcss/vite)
最新のv4アルファ/ベータ版を採用しているようです（設定が簡素化され、パフォーマンスが向上）
Component Primitives: Radix UI (@radix-ui/react-*)
アクセシビリティを考慮したヘッドレスUIコンポーネント（Dialog, Dropdown, Tabs, etc.）
Icons: Lucide React (lucide-react), React Icons (react-icons)
Utilities:
tailwind-merge, clsx: スタイルの動的結合
class-variance-authority: バリアント管理
tw-animate-css: アニメーション
next-themes: ダークモード対応

### 4. フォーム & バリデーション
Form Management: React Hook Form (react-hook-form)
Validation: Zod (zod) + Hookform Resolvers (@hookform/resolvers)

### 5. API 通信
Client Generator: Hey API (@hey-api/openapi-ts)
openapi.json から型安全なAPIクライアントを自動生成
HTTP Client: Axios (axios)
生成されたクライアントのバックエンドとして構成

### 6. 品質保証 & 開発体験
Linting/Formatting: Biome (@biomejs/biome)
ESLint/Prettierの代わりに、高速なRust製のBiomeを採用
E2E Testing: Playwright (@playwright/test)
DevTools: TanStack Router Devtools, TanStack Query Devtools

### プロジェクト構造の概要
src/routes: TanStack Routerのルート定義が含まれます。
src/client: OpenAPIから自動生成されたAPIクライアントコードが格納されています。
src/components: UIコンポーネント（おそらく 
components.json
 があることから shadcn/ui のような構成管理を使用している可能性があります）。
biome.json
: コードの品質とフォーマットルールを一元管理。
